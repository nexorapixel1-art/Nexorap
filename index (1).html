04 / Process

How a project runs

  1. 01

    Discover

    We learn your goals, users and constraints, then agree scope, timeline and budget in writing.

  2. 02

    Design

    Wireframes and visual direction first, then a clickable prototype you can test before any code is written.

  3. 03

    Build

    Development in short cycles with a working preview link, so you see real progress every week.

  4. 04

    Launch & support

    Testing on real devices, a managed release and a handover with documentation and ongoing support options.
